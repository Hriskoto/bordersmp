# Border SMP — GitHub Pages

Готовая статическая версия сайта, подготовленная из экспорта Framer.

## Публикация на GitHub Pages

1. Создай новый GitHub-репозиторий.
2. Загрузи **всё содержимое этой папки** в корень репозитория (не саму папку целиком).
3. Открой **Settings → Pages**.
4. В разделе **Build and deployment** выбери **Deploy from a branch**.
5. Выбери ветку `main` и папку `/ (root)`, нажми **Save**.
6. Подожди завершения публикации — адрес появится в Settings → Pages.

Не удаляй папки `framerusercontent.com`, `fonts.gstatic.com` и `vote`: они нужны сайту и его ресурсам.

## Важно

- Основная страница: `index.html`.
- Страница голосования: `vote/index.html`.
- Стили и анимации из экспорта Framer сохранены насколько это позволяет статический экспорт.
- Плашка «Made in Framer», Framer-analytics script и редакторская загрузка удалены.
- Сайт статический. Внешние функции, требующие сервер или базу данных, не превращаются автоматически в рабочие backend-функции.
- Чтобы подключить свой домен, настрой его в **Settings → Pages → Custom domain** и добавь требуемые DNS-записи у регистратора домена.
