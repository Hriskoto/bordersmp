eu.bordersmp.net

Three steps. A whole new world.

You’ll need Minecraft: Java Edition 1.21.11 to connect.

01

Launch Minecraft

Open the Minecraft Launcher, choose Java Edition 1.21.11, and press Play.

02

Add the server

Select Multiplayer, then Add Server. Name it Border SMP and enter eu.bordersmp.net as the Server Address.

03

Join Border SMP

Click Done, select Border SMP in your server list, and press Join Server. Your adventure begins here.

Can’t connect?

Check your version and server address. Need help? Ask in Discord.
